## 浏览器验收步骤

服务启动时使用独立空数据库，地图供应商请求应在加载前屏蔽，不自动抓取瓦片。建议用 390×844 iframe 或浏览器窄屏；这不等于真机后台定位测试。

1. 初始页面不应有「就去这里」，应有「试用新天地模拟探索」。点击并确认，页面标「模拟位置／非实时 GPS」，收到应用内主动提醒。
2. 查看卡片单程、往返、停留、合计与非导航假设；输入「我只有30分钟」，对话、主卡片、地图应同时为空且无「就去这里」。改为60分钟恢复可行候选。
3. 在附近发现卡点「稍后」选择1小时，确认前有到期时间；确认后该地点消失。刷新仍不出现。「记忆 → 暂缓与不感兴趣」显示期限，点「提前结束暂缓」并确认后重新判断。
4. 在附近发现卡点「不感兴趣」确认，该地点从地图和对话消失；刷新仍排除。在记忆的同一筛选撤销后恢复资格；历史原话仍在回顾。
5. 在记忆添加名称、类别、原因、来源，坐标留空，保存成功；列表标尚未定位，无地图链接或出发入口。可从「补充位置」输入WGS84点与来源，再进入当前筛选。
6. 调整时间后旧收件箱不应恢复不合预算地点。陈旧定位测试由受控时钟单测执行；没有伪装实际等待30分钟。
