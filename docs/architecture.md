# 产品与实现

目标：持续发现合适的探索机会，保留证据并随反馈修正。首版收窄地点发现范围到用户自己的想去集合，保留主动触发和持续记忆。

## 数据流

位置事件 / 60 秒定时器 → 检查长期授权 → 判断位置新鲜度和精度 → 获取未到访、未拒绝且信息有效的地点 → 时间预算筛选 → 冷却与去重 → 应用建议收件箱 → 反馈修改用户与地点的关系。

SQLite 的即时写事务保证多次触发不会重复发送。地点公共信息、用户关系状态和证据历史分别表达；当前尚未实现独立的概率性偏好记忆。

## 文件

- app.py：HTTP API、存储、地理筛选、任务调度。
- language.py：可选本地模型意图解析，固定本机端点，不向外部模型发送位置。
- static/：中文界面、定位授权、手动输入和反馈。
- tests/：闭环行为、过期、授权、并发和数据清除测试。

## 下一步实现顺序

1. 确定首发城市、手机平台和地图供应商；落实坐标系及数据保存限制。
2. 原生位置事件上传、通知授权与通知投递回执。
3. 地点搜索 / 详情 / 路线适配器，按字段保存来源和失效时间；推荐前真实核实。
4. 模型工具循环：检索个人记忆、搜索地点、刷新详情、查询路线；确定性执行层继续掌管权限、频控和发送。
5. 基于证据的偏好假设、置信度、纠正和衰减；常活动区域聚类。
6. 照片授权、用户确认到访、旅程回顾，再验证探索满意度及主动建议时机。

自然语言解析仅做本地可选接入，不能据此声称已实现完整自主模型 Agent。首版重点验证存储、感知事件、主动决策和反馈更新的工程闭环。
