# Wander · 漫游

一个本地优先、持续维护个人地点记忆并主动提出探索建议的原型。Python 3.9+，核心无第三方依赖。

## 运行

```sh
python3 app.py
```

打开 http://127.0.0.1:8765 。加入真实的想去地点（WGS84 坐标、来源和原因），更新位置，开启主动建议。

可选自然语言入口：安装并运行 [Ollama](https://docs.ollama.com/api/chat)，准备支持 JSON 输出的模型，然后：

```sh
WANDER_MODEL=你的本地模型名称 python3 app.py
```

自然语言可查询推荐或向已知地点添加到访、拒绝、稍后和修正反馈。模型只解析意图，执行层验证地点和操作类型，反馈保存用户原话。模型错误仍可能误分类，可在证据列表检查；此模块不替代完整偏好推理。

## 已实现

- SQLite 持久化地点、来源、有效期、用户明确兴趣、位置和反馈证据。
- 位置更新事件及每分钟后台检查，产生应用内主动建议；可关闭。
- 过旧或不精确的位置不触发；过期地点不推荐；6 小时冷却和 7 天地点去重。
- 按可用时间筛选：来回步行粗估加 20 分钟停留；明确标注非实际导航路线。
- 到访不等于喜欢；稍后保留想去；明确拒绝移出推荐；证据保留历史。
- 手动提供新来源刷新信息；删除全部个人数据。
- 本地 Ollama 自然语言意图解析可选，未配置时结构化闭环照常运行。

## 真实边界

这是单用户本地技术原型，不是完整移动产品。没有手机后台定位、系统推送、自动地图检索、实时营业核实、照片导入、自动游记、区域熟悉度聚类或长期偏好学习。定时器只在 Python 进程运行时有效；浏览器关闭后不采集位置，但服务仍会基于未过期位置检查。地点有效期 7 天只是原型维护策略，不证明内容真实。输入来源由用户负责核实。

地图使用 WGS84 坐标，中国地图的 GCJ-02/BD-09 坐标不可直接混用。距离为球面直线距离，不考虑道路、入口、障碍或交通。

所有数据保存在忽略提交的 `data/wander.db`，默认不上传。服务器只绑定本机，拒绝跨域写入。没有账户隔离和互联网部署所需的认证；请保持本机运行。位置记录在后续位置更新时清理 30 天以前的数据。

## 新天地主动发现预览

已增加一个有公开来源的三地点附近候选集（复兴公园、思南书局、思南公馆）。它们是系统发现候选，不写入用户的收藏或兴趣证据。坐标为近似 WGS84 展示点，非精确入口；来源支持地点身份与地址，不证明实时营业。

调用 `POST /api/demo-xintiandi`（JSON `{}`）可明确启用新天地模拟位置与主动建议。位置保持普通 30 分钟有效期，不会伪装为持续 GPS，也不会在刷新时自动续期。真实定位更新后会退出模拟标记。

页面打开时自动检查，后台每分钟也检查；送达应用内收件箱，继续遵守冷却与去重。拒绝的候选不再推荐；离开 2 公里范围不推荐附近候选。当前候选集不是完整地图搜索服务，也不包含系统通知。

## 地图主视角

探索页以交互地图为主画布：位置与附近地点标记、类别筛选、缩放／回到起点、点选地点联动底部卡片。对话与记忆可展开，地图本身不绘制或声称提供导航路线。

地图使用 [Leaflet 1.9.4](https://leafletjs.com/) 和 OpenStreetMap 标准底图，需要联网；地图组件或底图不可用时明确显示加载失败，附近地点卡片仍可查看。请求底图时地图服务会获得当前视口对应的瓦片范围；本地新天地预览使用明确标注的模拟位置。真实点位的权限和数据来源沿用现有定位入口。

## 微缩城市外观

地图上增加 SVG 立体景点、Canvas 人物和车辆动画、演示聚集光晕，以及可暂停的动画控制。遵循 `prefers-reduced-motion`；页面不可见时不绘制动画，画布按设备像素比缩放并限制到 2 倍。

**所有人物、车辆、轨迹和热度均为合成演示，不代表真实用户、道路交通或实时客流。** 景点卡片与地图图例明确显示演示标签；当前没有客流数据接入。演示热度不参与推荐排序。实际地图点位与展示动画分开维护。

## 地点事实与体验证据

- `place_data.py` 接入高德官方 POI 2.0 文本搜索（当前限定上海）。设置服务端环境变量 `AMAP_WEB_SERVICE_KEY` 后重启：

  ```sh
  AMAP_WEB_SERVICE_KEY=你的Web服务密钥 python3 app.py
  ```

  不要把密钥提交到仓库。当前运行环境没有密钥，真实高德请求尚未做端到端验证；自动测试使用模拟响应验证匹配、缺字段与异常分支。
- 在地图卡片点“公开体验／依据”，查询评分、人均、营业描述等可用字段。唯一名称与保守距离检查失败时不展示结果，避免同名地点误配；高德 GCJ-02 坐标不直接覆盖现有 WGS84 坐标，也未声称已修正入口位置。
- 高德结果仅用于当前响应，不持久化到 SQLite；不请求评论正文、不把评分当成实时客流。上线前仍需按所用服务权限确认展示、存储和商业使用要求。
- 复兴公园附一篇人工核对的公开 Trip.com 游记摘要：Travelwithfei，2025-06-19，核对日 2026-11-01。保留链接、作者、日期、1 篇样本量和局限，不复制完整文章，不作平台整体口碑总结。原文：[Fuxing Park Shanghai](https://www.trip.com/moments/detail/shanghai-2-133118715/)。这是补充样本，不是大众点评或 Google 评论接口接入。
- 可补充带 HTTPS 来源、作者、发布日期的体验摘要，保存为 `user_supplied`，明确显示“未核实原文”。服务器不自动抓取该链接。摘要和个人喜好证据分开；清除个人数据同时清除用户补充的体验。
- 大众点评／Google 评论未接入；当前 OSM 地图不混用 Google Places 数据。实时人流仍未接入，卡通热度与动画均为演示。

接口：`POST /api/place-context` 传 `place_id` 返回事实与来源；`POST /api/experiences` 添加用户提供的体验摘要。响应不会返回密钥，缺密钥或接口错误都有明确状态。
